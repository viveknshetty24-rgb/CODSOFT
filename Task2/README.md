# Task 2: Student Grade Calculator 📊

This is my **Task 2 submission for the CodSoft Java Internship**.

The project is a **Java console-based Student Grade Calculator** that takes marks of multiple subjects, calculates the total marks, average percentage, and assigns the corresponding grade.

## 🚀 Features
- Input marks for each subject
- Calculate total marks
- Calculate average percentage
- Assign grades based on percentage
- Display final result with:
  - Total Marks
  - Average Percentage
  - Grade
