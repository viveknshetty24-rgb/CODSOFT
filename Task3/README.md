Task 3: ATM Interface

This is my Task 3 submission for the CodSoft Java Internship.

The project is a Java console-based ATM Interface where the system allows users to perform basic banking operations such as withdrawing money, depositing money, and checking account balance. The ATM is connected to a bank account class that stores and updates the balance securely.

Features
Class representing ATM machine
Class representing user bank account with balance storage
Withdraw money with balance validation
Deposit money into account
Check current account balance
Input validation for safe transactions (e.g., insufficient balance check)
Appropriate messages for successful and failed transactions
User-friendly menu-driven interface
