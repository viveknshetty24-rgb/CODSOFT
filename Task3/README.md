# Task 3: ATM Interface 🎯

---

This is my **Task 3** submission for the **CodSoft Java Internship**.

The project is a **Java console-based ATM Interface** where a user can manage their bank account by withdrawing money, depositing money, and checking their balance.

## 🚀 Features

---

* **ATM Machine Class** to represent the interface
* **User Bank Account Class** to store the balance
* **Menu Options** for the user:
    * Withdraw money
    * Deposit money
    * Check Balance
* **Methods** implemented for each action:
    * `withdraw(amount)`
    * `deposit(amount)`
    * `checkBalance()`
* **Input Validation** to check for:
    * Sufficient balance for withdrawals
    * Valid input amounts
* **Simple Messages** to show if a transaction was a success or failure
